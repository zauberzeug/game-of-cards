**Landed.** `render_table`'s `verbose >= 1` block now emits the overlay
above the `awaiting:` advisory, via two new helpers next to
`waiting_impedes`:

- `live_impeded(card)` — the "actively impeded" gate (non-terminal, not
  a draft, `waiting_impedes`).
- `format_waiting_overlay(card)` — the three-shape detail line, `""`
  when there is nothing live to show.

**The gate was deliberately not re-inlined.**
[waiting-impedes-callers-reimplement-the-terminal-status-liveness-gate-and-drift](../waiting-impedes-callers-reimplement-the-terminal-status-liveness-gate-and-drift/)
catalogues that exact gate as re-stated at ~5 sites in three phrasings
and predicts the next read surface will copy it and drift. The
`--waiting` filter already held the identical expression verbatim, so
both it and the new table line route through `live_impeded` — the copy
count drops rather than rising. The meta-fix's helper-shape decision
stays open and unprejudiced; `live_impeded` folds into whatever it
picks.

**Ordering is a contract, not a preference.** `awaiting:` is the
*advisory* axis and its text ends "(you may start)". Emitting the hard
impediment below it would leave an impeded card whose only
waiting-shaped line asserts the opposite of its state. A test pins the
order.

**Malformed `waiting_until` is echoed, not prettified.**
`_format_waiting_until_for_message` falls back to `_date_part`, whose
10-character slice would render the unparseable `2099-01-01xx` as the
clean date `2099-01-01` — reintroducing, in a new surface, the
truncation
[waiting-impedes-truncates-malformed-waiting-until-to-a-valid-prefix-date](../waiting-impedes-truncates-malformed-waiting-until-to-a-valid-prefix-date/)
removed from the read guard. The line prints `2099-01-01xx — malformed`
instead.

**Scope held at the detail-line levels.** The terse verbose-0 table
keeps one row per card; it carries no detail line for `summary`,
`awaiting`, or `worker` either, and `Skill(scan-deck)` documents it as
"titles + contribution only — use sparingly". A terse-view marker is a
glyph question that belongs with the open
[board-marks-pullable-and-impeded-cards-with-the-same-hourglass-glyph](../board-marks-pullable-and-impeded-cards-with-the-same-hourglass-glyph/).
`reproduce.py` scopes pass/fail accordingly and prints the terse rows
